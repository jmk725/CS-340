# CS-340
I write maintainable, readable, and adaptable programs by using clear structure, modular design, meaningful variable names, and thorough documentation. In this project, I separated database operations into a dedicated CRUD Python module created in Project One. This allowed the dashboard code to focus on user interface and visualization logic while the module handled all database interactions. Working in this way provided several advantages. It improved maintainability because database logic was centralized in one location, making updates easier if connection details or query behavior change. It also improved readability, since the dashboard code remained concise and easier to understand, and increased adaptability because the same module can be reused across multiple applications without rewriting database access code. In the future, this CRUD module could be reused in other projects that require MongoDB access, such as web applications, data analysis tools, or administrative interfaces, and it could be extended to support additional collections, authentication methods, or more complex queries.

When approaching a problem as a computer scientist, I begin by understanding the requirements, breaking the problem into manageable components, and designing a solution that balances correctness, efficiency, and usability. For this project, I analyzed Grazioso Salvare’s need to identify dogs suitable for search-and-rescue training and designed a database structure and dashboard that could support filtering, visualization, and interaction. This project differed from previous assignments because it required integrating multiple technologies—database design, backend programming, and user interface development—into a single cohesive system. Instead of solving an isolated programming problem, I had to consider real-world factors such as data organization, user experience, and scalability. In future projects involving client requests, I would continue using techniques such as requirement analysis, modular design, iterative testing, and user-centered development to ensure that solutions remain flexible as needs evolve.

Computer scientists design systems that transform raw data into meaningful information and automate complex tasks. Their work enables organizations to operate more efficiently, make informed decisions, and solve problems that would otherwise require significant manual effort. In this project, the dashboard helps Grazioso Salvare quickly identify dogs that meet specific training criteria from a large dataset. Rather than manually reviewing records, staff can filter, visualize, and analyze information in seconds. This reduces human error, improves decision-making, and allows the organization to devote more time to training rescue animals rather than managing data. Projects like this demonstrate how software solutions can directly support mission-driven organizations by providing efficient tools for data analysis and visualization, ultimately helping them perform their work more effectively and deliver greater impact.
